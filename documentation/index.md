## Tools and workflows

- **[Needle Engine](./needle-engine)** - Overview, features, and examples. New to the engine? Read [why it exists](./why).
- **[Unity](./unity/), [Blender](./blender/), and [three.js](./three/)** - Set up your preferred workflow.
- **[Needle Mesh Baker](./products/needle-mesh-baker)** - Reduce geometry, bake materials, and optimize models.
- **[Needle Inspector](./three/needle-devtools-for-threejs-chrome-extension)** - Inspect and debug live three.js scenes in Chrome DevTools.
- **[AI tools](./ai/)** - Set up coding assistants and connect them to live scenes with the Needle MCP Server.
- **[Needle Cloud](./cloud/)** - Host projects and manage assets and licenses.
